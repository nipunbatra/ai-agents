### **6 More Major Agent Milestones (August 2025 – November 2026)**

**1. ChatGPT Atlas (21 Oct 2025)**
OpenAI launched an AI-native web browser for macOS with ChatGPT built directly into the browsing experience, featuring an "Agent Mode" that could navigate sites and complete tasks on the user's behalf. *(Note: Atlas was later deprecated and shut down on 9 Aug 2026, with its agent features folded into the ChatGPT desktop app.)*
*Source: OpenAI Blog / TechCrunch*

**2. Anthropic Claude Duet (21 Oct 2025)**
Anthropic launched a research preview of a proactive agent app. Unlike standard chatbots that wait for a prompt, Duet runs in the background on its own cloud computer, surfaces items needing attention, and continues working on tasks even when the user's device is closed. 
*Source: Anthropic News*

**3. Google Deep Research Max (21 Apr 2026)**
Google launched an evolved version of its Deep Research agent built on the Gemini 3.1 Pro model. It was optimized for extended compute and slower background jobs, allowing users to switch off web access and have the agent work exclusively from custom data supplied through remote MCP servers.
*Source: Google Cloud Blog*

**4. ChatGPT Work (9 Jul 2026)**
OpenAI introduced a dedicated agentic mode inside ChatGPT (alongside Chat and Codex) powered by GPT-5.6. Instead of conversational answers, users hand ChatGPT Work a goal, and it autonomously pulls context from connected tools (Slack, Drive, Salesforce) to produce finished deliverables like slide decks, spreadsheets, and reports.
*Source: OpenAI Blog*

**5. ChatGPT Dots (29 Sep 2026)**
Announced at OpenAI's DevDay, "Dots" are always-on agents powered by GPT-6 Astra. Each Dot is assigned its own cloud computer and browser, allowing it to continuously pursue user-defined goals, monitor data, and execute multi-step workflows 24/7 without requiring a persistent local session.
*Source: OpenAI DevDay Keynote / TechCrunch*

**6. Agentic AI Foundation (AAIF) Expands with 4 New Projects (22 Oct 2026)**
At AGNTCon + MCPCon North America, the Linux Foundation's AAIF announced the addition of four major open-source agent projects to its governance: *Agent Skills* (donated by Anthropic), *Open Responses* (OpenAI), *OpenEnv* (Hugging Face), and *OpenSandbox* (Alibaba), standardizing how agents gain capabilities and where they run safely.
*Source: Linux Foundation Press Release*
